# eDu Live Frontend (Vite + React)

Modern React frontend built with Vite and Tailwind CSS v4.

## 🚀 Quick Start

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

Runs on `http://localhost:3000`

### Build

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```

## 📁 Project Structure

```
src/
├── components/      # Reusable components
├── contexts/        # React contexts (Auth)
├── pages/           # Page components
├── services/        # API services
└── main.jsx         # Entry point
```

## 🎨 Styling

- **Tailwind CSS v4** - Utility-first CSS
- **Inter Font** - Google Fonts
- **Red/Rose Theme** - Matching Laravel design

## 🔧 Configuration

Create `.env` file:

```env
VITE_API_URL=http://localhost:5000/api/v1
```
